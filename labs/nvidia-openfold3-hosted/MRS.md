# OpenFold3 requirements

BIO-007, 2026-09-20. Proposed requirements; implementation approval and research qualification remain pending.

Provide one manually authored Lab for the exact NVIDIA-listed OpenFold3 release, with proteins, DNA, RNA and ligands represented as explicit entities in one requested complex. Support native protein/RNA alignments, protein paired alignments, protein templates, chain multiplicity, diffusion sample count and documented output formats without silent input modification. Current target is NIM 1.6.0; hosted deployment equivalence must be established separately.

1. Identify every entity and requested chain copy explicitly. Preserve standard protein/DNA/RNA sequence, 5′→3′ nucleic-acid direction, ligand SMILES or CCD identity, chemical graph/stereochemistry evidence, original inputs and provenance. Never invent a complementary strand, MSA hit, ligand correspondence, chain ID or omitted atom as scientific evidence.
2. Bind each alignment to its entity/chain and exact query. Protein requires an unpaired or paired MSA; RNA requires an MSA. An explicitly supplied query-only alignment is zero-hit evidence, not homology evidence. Preserve native A3M insertion semantics or CSV keys/rows and paired row association. Do not infer species pairing from equal row counts.
3. Preserve all provided protein templates with checksums and source identity, and report native selection/mapping uncertainty. Templates for other molecule types are unsupported. Hosted documentation lacks template fields present in current NIM; an accepted HTTP response alone does not establish template use.
4. Return every diffusion sample, original coordinate artifact, native ranking and confidence values, chain/residue/atom mappings and availability indicators. No sample may be discarded merely to fit an existing single-structure profile. Finite sampling is not biological time evolution.
5. Require parseable finite coordinates, unique chain/residue/atom identity, expected chain multiplicity, exact polymer sequence and valid ligand composition/graph mapping. Unavailable chemical graph or atom correspondence must be explicitly unresolved and must prevent claiming qualified downstream ligand compatibility. Coordinate plausibility is not experimental accuracy.
6. Preserve confidence_score, complex_plddt_score, complex_pde_score, ptm_score and iptm_score as distinct OpenFold3 quantities. In actual monomer responses iptm_score is null despite numeric-only hosted documentation; never replace it with zero. Confidence/ranking is not binding affinity or measured structure accuracy. Boltz profiles do not apply.
7. Canonical io, runtime SignalSpec declarations and Lab maps_to agree, with explicit one-shot execution, bounded network/compute observations, secure worker credentials and portable artifacts. Never persist credentials. Exact request UUID/hash resumes an existing operation; observation timeout does not authorize duplicate submission.
8. Verify each modality and interface with legitimate sourced fixtures, predeclared technical checks and captured native/adapter comparisons. Use all complete inputs. Negative checks must identify malformed input before network submission; native failures remain recorded. Local tests, native API execution, managed runtime validity and research qualification are separate gates.
9. Scientific benchmarks must match intended claims: monomer lDDT/TM-score and aligned RMSD; protein/protein or nucleic-acid interface mapping and suitable complex metrics; ligand graph/stereochemistry and symmetry-aware pose metrics. Pin panel provenance, training/template leakage controls, checkpoint/CCD/MSA versions, uncertainty, comparator settings and scientifically justified tolerances before acceptance. No arbitrary threshold from a single fixture.
10. Establish exact code/weights/container/database/CCD identities and artifact-specific execution/redistribution rights. Current model card, hosted schema and upstream preview have differing version/term descriptions. Existing Hub publication or provider confidence establishes neither identity equivalence nor scientific accuracy. Private evidence review and approval of an exact public release remain independent.
